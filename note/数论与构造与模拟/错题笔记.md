# 算法错题笔记 — 模拟/区间贡献题型（C 题）

本笔记针对 C 题（小苯分裂模拟）的解题误区进行总结，归纳常见错误及对应的修正方法。

## 题目回顾

在数轴正半轴上有若干小苯，初始位置由数组 `a` 表示，每秒重复执行：

1. 若仍有小苯存在，小红清除当前最小坐标的所有小苯。
2. 所有剩余小苯各自分裂：位置在 `x` 的小苯生成一个新小苯留在 `x`，并生成一个新小苯移动到 `x+1`。

求经过 `k` 秒后仍然存在小苯的位置数目。

## 常见错误

* **未对坐标排序。** 题目只保证位置互不相同，但输入顺序可能无序。若不排序直接计算相邻差，会得到错误结果。

* **漏处理基础边界。** 两个特殊情况应提前处理：
  - 当 `k == 0` 时，没有任何操作，答案即为输入小苯数量 `n`；
  - 当 `n == 1` 且 `k > 0` 时，初始唯一的小苯首秒必被清除，后续不会出现其它位置，答案是 `0`。

* **特判不合理。** 有些实现写了诸如 `if (n == 2) cout << 2;` 之类的特判，这是错误的。只需按照通用逻辑计算，不需对某个 `n` 直接输出固定值。

* **状态更新遗漏。** 在计算相邻坐标间隔时需更新前一个坐标，例如：

```cpp
last = a[i]; // 更新 last
```

缺失此更新会导致后续计算总是与同一个元素比较。

* **未使用长整型。** 分裂后的位置可能大于初始最大值，计算间隔加和时应使用 `long long`，否则中间结果可能溢出。

* **未考虑 k=0 时的间隔贡献。** 答案的核心来自相邻间隙 `gap = a[i] - a[i-1] - 1` 和秒数 `k`。真正的贡献是 `min(gap, k)`。若 `k == 0`，贡献为 0。漏处理这一点会出现错误。

## 正确做法要点

1. **排序数组。** 使用 `sort(a.begin(), a.end())` 先对小苯位置排序。

2. **处理基础情况：**
   - `k == 0` 时直接输出 `n`；
   - `n == 1 && k > 0` 时输出 `0`。

3. **计算相邻空隙贡献。** 当 `k > 0` 且 `n ≥ 2` 时，首秒清除最小坐标，之后每个相邻差 `a[i] - a[i-1] - 1` 的空隙最多能被扩展 `k` 次。注意从第三个元素 (`i = 2`) 开始计算，因为第一秒后新的左端为原 `a[1]`。

```cpp
long long ans = n; // 基本贡献，初始还有 n 个位置
for (int i = 2; i < n; i++) {
    long long gap = a[i] - a[i - 1] - 1;
    ans += min(gap, k);
}
```

4. **更新状态。** 每次循环结束后，应更新前一个坐标变量 `last`，确保下轮比较正确。

5. **使用长整型。** 所有中间变量和答案应使用 `long long` 类型，保证计算不会溢出。

通过上述方法可以避免常见错误，准确计算分裂之后仍然存在小苯的坐标数目。
